# Áudio das páginas

`public/assets/page-turn.wav` usa uma gravação real de uma folha, no lugar do ruído sintetizado anterior.

- **Page Turn (1)**, de OwlStorm (Ashe Kirk / Owlish Media).
- Página original e licença CC0 1.0: https://freesound.org/people/OwlStorm/sounds/151220/
- Prévia de alta qualidade fornecida pela própria plataforma: https://cdn.freesound.org/previews/151/151220_140737-hq.mp3
- Preparação: conversão para WAV mono 44,1 kHz, remoção de graves, filtro suave, fades e volume menor. Script reproduzível `scripts/create-paper-audio.py`; exige ffmpeg.
- O som só é iniciado após interação. O leitor pode desligá-lo; nenhuma gravação externa é buscada durante o uso do álbum.

A licença foi conferida na página do autor em 16/10/2026. A qualidade percebida em alto-falantes/fones e o desbloqueio de áudio no celular ainda exigem escuta no navegador.
